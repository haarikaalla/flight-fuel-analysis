# Data and code availability statement

The development data are the EUROCONTROL PRC 2025 Aircraft Fuel Burn
Estimation Data Challenge release, DOI `10.5281/zenodo.19184662`, licensed CC BY
4.0. Raw files are excluded from Git and accepted only after published checksum
verification. The committed audit records source hashes, periods, counts and
label limitations.

OpenSky historical trajectories and ERA5 meteorology are not redistributed.
Researchers must obtain them through legitimate access routes, accept applicable
terms and record immutable retrieval information. EASA Data4Safety is a
controlled partnership platform and is not described as open data. US BTS
carrier fuel tables may support aggregate plausibility checks but are not
flight-level truth.

All new research code, fixed configurations, tests, outputs and manuscript
artifacts live under `research_q1/` on branch `q1-research-extension`. The
original dashboard and source remain unchanged. The inherited upstream
repository did not contain a software license at fork time; permission from the
upstream author is required before redistributing derivative software.

No future-confirmation labels are included. Their one-time evaluation requires
explicit authorization after the protocol, code commit and input hash are
frozen.
